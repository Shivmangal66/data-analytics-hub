1. What is Python?

Python is a high-level, general-purpose programming language.

It is designed with a simple and readable syntax, which makes it easier for beginners to understand programming concepts.

Python is used in many different areas such as web development, automation, software development, artificial intelligence, machine learning and data analytics.

Why do we learn Python?

  • Python has simple and readable syntax.
  • It is useful for beginners as well as professional developers.
  • It has many powerful libraries.
  • It is widely used in Data Analytics, AI and Machine Learning.
  • Python can be used to automate repetitive tasks.
💡 Remember: Python is not only used for making websites. It can also be used for automation, data analysis, AI, machine learning and many other tasks.

3. Printing Multiple Values

The print() function can display more than one value.

You can separate multiple values using commas.

Example

name = "Shiv" age = 18 print("Name:", name) print("Age:", age)

Here Python prints both the text and the values stored in the variables.

4. Introduction to Variables

A variable is a name used to store a value.

Think of a variable like a labelled box. The label is the variable name, and the value is the information stored inside that box.

Example

name = "Shiv" age = 18 course = "Python" print(name) print(age) print(course)

Important Rules

  • Variable names should be meaningful.
  • A variable can store different types of data.
  • Python does not require you to declare the data type separately.
  • Variable names are case-sensitive.

5. Introduction to Data Types

A data type tells Python what kind of value is stored in a variable.

For example, a person's age is normally an integer, while a person's name is a string.

Common Python Data Types

  • int — whole numbers such as 10, 25 and 100
  • float — decimal numbers such as 10.5 and 99.99
  • str — text such as "Python"
  • bool — True or False

Q1. What is Python?

Python ek high-level, interpreted aur general-purpose programming language hai. Python ka use web development, data analytics, artificial intelligence, machine learning, automation aur software development mein kiya jata hai.

Answer:

Python is a high-level programming language known for its simple syntax and readability. It is widely used in Data Analytics, Machine Learning, AI, Web Development and Automation.

Q2. What is a Variable in Python?

Variable kya hota hai? Python mein variable kaise create karte hain? Example ke saath explain karo.

Answer:

Variable ek naam hota hai jiska use data ko store karne ke liye kiya jata hai. 

name = "Shiv"
age = 18
marks = 85

Yahan name, age aur marks variables hain. Python automatically variable ke data ka type identify kar sakta hai.

Q3. What are Data Types in Python?

Python ke important data types ko examples ke saath explain karo.

Answer:

Data type batata hai ki variable ke andar kis type ka data stored hai. 

name = "Shiv"       # String
age = 18            # Integer
height = 5.8        # Float

Common Python data types:

  • String — Text data
  • Integer — Whole numbers
  • Float — Decimal numbers
  • Boolean — True / False
  • List — Multiple values
  • Tuple — Ordered collection
  • Dictionary — Key-value data
