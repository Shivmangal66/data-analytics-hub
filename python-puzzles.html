01. What is Python?

📚 Theory

Python is a high-level, interpreted and general-purpose programming language. It is widely used in web development, automation, data analysis, machine learning, artificial intelligence and software development.


Python has a simple and readable syntax, which makes it useful for beginners as well as professional developers.

05. Strings

📚 Theory

A string is a sequence of characters enclosed inside single quotes, double quotes or triple quotes . Strings are used to store text data.

Strings can be written using:

  • Single quotes: 'Hello'
  • Double quotes: "Hello"
  • Triple quotes: """Hello"""
