🧩 Functions in Python

A function is a reusable block of code that performs a specific task. Functions help us organize programs, reuse code, and avoid repeating the same code.

📌 Why Use Functions?

  • Reuse code
  • Reduce duplicate code
  • Make programs easier to understand
  • Make debugging easier
  • Break large programs into smaller parts

1️⃣ Creating a Function

We create a function using the def keyword. 

def greet():
    print("Hello, Python!")

greet()

Output:

Hello, Python!

2️⃣ Function with Parameters

Parameters allow us to send information into a function. 

def greet(name):
    print("Hello", name)

greet("Shiv")

Output:

Hello Shiv

3️⃣ Multiple Parameters

def add(a, b):
    print(a + b)

add(10, 20)

Output:

30

4️⃣ Return Statement

The return statement sends a value back from a function. 

def add(a, b):
    return a + b

result = add(15, 25)

print(result)

Output:

40

5️⃣ Default Parameter

A default parameter is used when no value is provided. 

def greet(name="Student"):
    print("Hello", name)

greet()

Output:

Hello Student

6️⃣ Keyword Arguments

Keyword arguments allow us to pass values using parameter names. 

def student(name, age):
    print("Name:", name)
    print("Age:", age)

student(age=18, name="Shiv")

Output:

Name: Shiv
Age: 18

7️⃣ Function with a List

We can pass a list as an argument to a function. 

def show_items(items):

    for item in items:
        print(item)


fruits = ["Apple", "Banana", "Mango"]

show_items(fruits)

Output:

Apple
Banana
Mango

8️⃣ Function for Calculation

def calculate_total(price, quantity):

    return price * quantity


total = calculate_total(100, 5)

print("Total:", total)

Output:

Total: 500

9️⃣ Even or Odd Using Function

def check_number(number):

    if number % 2 == 0:
        return "Even"
    else:
        return "Odd"


print(check_number(10))
print(check_number(7))

Output:

Even
Odd

🔟 Find Maximum Number

def find_max(a, b):

    if a > b:
        return a
    else:
        return b

1️⃣4️⃣ Data Analytics Example — Sales

Functions are useful in data analytics because the same calculation can be reused for different datasets. 

def total_sales(sales):

    total = 0

    for amount in sales:
        total += amount

    return total


sales = [500, 1200, 800, 2500]

result = total_sales(sales)

print("Total Sales:", result)

Output:

Total Sales: 5000
