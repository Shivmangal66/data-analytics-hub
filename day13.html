DAY 13 • EXCEL MASTERY

VLOOKUP

Learn how VLOOKUP can search for a value in a table and return related information automatically.

🎯 Today's Goal

Understand how VLOOKUP works and use it to retrieve information from a table using a lookup value.

📚 What You Will Learn

🔎 Lookup Value

The value you want Excel to search for in the first column of your table.

📋 Table Array

The range containing the lookup data and the information you want to return.

🔢 Column Index

The number of the column from which Excel should return the result.

🎯 Exact Match

Use FALSE when you want an exact match for the lookup value.

💡 VLOOKUP Syntax

=VLOOKUP(lookup_value, table_array, col_index_num, FALSE)

VLOOKUP searches vertically through the first column of a selected table and returns a value from another column in the same row.

📊 Worked Example

ID Name Department Salary
101 Shiv IT 55000
102 Rahul Sales 45000
103 Aman HR 50000
104 Priya Finance 60000

🔍 Find an Employee's Name

Suppose cell F2 contains Employee ID:

F2 = 103

=VLOOKUP(F2,A2:D5,2,FALSE)

Result → Aman

💰 Find Salary

To return the Salary column, use column number 4.

=VLOOKUP(F2,A2:D5,4,FALSE)

Result → 50000

⚠️ Common Mistakes

❌ Wrong Column

The lookup value must be in the first column of the selected table.

❌ Wrong Column Number

Check the column index carefully.

❌ Missing FALSE

Use FALSE when an exact match is required.

❌ Incorrect Range

Make sure the table range includes both the lookup and result columns.

📝 Practice Task

Create an employee table with ID, Name, Department and Salary.


Enter an Employee ID in another cell and use VLOOKUP to automatically display the employee's Name.


Then create another VLOOKUP formula to return the employee's Salary.
