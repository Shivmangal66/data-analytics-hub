HTML Introduction

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of a web page. HTML tells the browser how different pieces of content should be organized and displayed.

Why is HTML Used?

  • To create web pages.
  • To structure text and content.
  • To add links and images.
  • To create tables and forms.
  • To build the basic structure of websites.

HTML Editors

An HTML editor is a software application used to write, edit and manage HTML code. A simple text editor can be used to create HTML files.

Common HTML Editors

  • Notepad
  • Visual Studio Code
  • Sublime Text
  • Notepad++

Basic Workflow

  • Open an editor.
  • Write HTML code.
  • Save the file with the .html extension.

Basic HTML Structure

Every standard HTML document follows a basic structure. The document normally contains the DOCTYPE declaration, html element, head section and body section.

Main Parts

  • DOCTYPE: Defines the document as HTML5.
  • html: The root element.
  • head: Contains page information.
  • body: Contains visible page content.

Semantic HTML

What is Semantic HTML?

Semantic HTML uses elements that clearly describe the meaning and purpose of their content.

Key Points

  • <header> represents introductory content.
  • <nav> contains navigation links.
  • <main> contains the main content.
  • <section> groups related content.
  • <article> represents independent content.
  • <footer> represents footer information.
