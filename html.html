HTML Introduction

HTML is a markup language used to structure content on the web. It tells the browser what different parts of a webpage represent.

Key Points

  • HTML is not a programming language.
  • HTML uses tags.
  • HTML creates the structure of webpages.
  • HTML works with CSS and JavaScript.

HTML entities are special codes used to display characters that have special meaning in HTML.
