HTML Introduction

HTML stands for HyperText Markup Language. It is used to create the structure and content of web pages.

HTML is not a programming language. It is a markup language that uses elements and tags to tell the browser how content should be displayed.

Basic HTML Page

<!DOCTYPE html> <html> <head> <title>My Page</title> </head> <body> <h1>Hello World</h1> <p>My first webpage.</p> </body> </html>

HTML Elements

An HTML element normally consists of an opening tag, content and a closing tag.

<p>This is a paragraph.</p>

Some HTML elements do not require a closing tag. For example, the image element uses <img>.

HTML Attributes

HTML attributes provide additional information about an HTML element. Attributes are written inside the opening tag.

For example, the href attribute tells the browser where a link should go.

<a href="https://example.com"> Visit Website </a>

HTML Headings

HTML provides six heading levels from h1 to h6. The h1 heading is the largest and h6 is the smallest.

<h1>Heading 1</h1> <h2>Heading 2</h2> <h3>Heading 3</h3> <h4>Heading 4</h4> <h5>Heading 5</h5> <h6>Heading 6</h6>

HTML Images

The <img> element is used to display an image on a webpage.

The src attribute specifies the image location and the alt attribute provides alternative text.

<img src="image.jpg" alt="My Image">

HTML Tables

HTML tables are used to organize information into rows and columns.

The <table> element creates the table. The <tr> element creates a row, while <th> creates a heading cell and <td> creates a data cell.

Example

<table border="1"> <tr> <th>Name</th> <th>Course</th> </tr> <tr> <td>Shiv</td> <td>HTML</td> </tr> </table>

HTML Lists

HTML provides different types of lists for displaying related information.

Unordered List

An unordered list uses the <ul> element. Each item is created using <li>.

<ul> <li>HTML</li> <li>CSS</li> <li>Python</li> </ul>

Ordered List

An ordered list uses the <ol> element. The browser automatically numbers the items.
