HTML Introduction

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

HTML uses elements and tags to define headings, paragraphs, links, images, tables and many other parts of a webpage.

HTML Elements

An HTML element usually contains an opening tag, content and a closing tag.

<p>Hello World</p>

HTML Headings

HTML provides six heading levels from h1 to h6.

<h1>Heading 1</h1> <h2>Heading 2</h2> <h3>Heading 3</h3>
