HTML Links

An HTML link is used to connect one webpage to another webpage, file, section, or external resource. Links are created using the <a> element.

Important Attribute

  • href — Specifies the destination of the link.
  • target — Specifies where the linked page opens.

HTML Images

HTML images are used to display pictures on a webpage. The <img> element is used to add an image. The img element does not require a closing tag.

Important Attributes

  • src — Specifies the image location.
  • alt — Provides alternative text.
  • width — Sets image width.
  • height — Sets image height.

HTML Favicon

A favicon is a small icon associated with a webpage. It is commonly displayed in the browser tab next to the page title.

How Favicon Works

A favicon is normally added inside the <head> section using the <link> element.

HTML Tables

An HTML table is used to organize and display data in rows and columns. Tables are useful for presenting structured information such as student records, product details, marks and prices.

Table Elements

  • <table> — Defines the table.
  • <tr> — Defines a table row.
  • <th> — Defines a table heading.
  • <td> — Defines table data.

HTML Lists

HTML lists are used to organize related items. HTML provides ordered lists, unordered lists and description lists.

Unordered List

An unordered list displays items using bullet points. It is created using <ul>.

Ordered List

An ordered list displays items in a numbered sequence. It is created using <ol>.

HTML Description Lists

A description list is used to display terms together with their descriptions. It is useful when each item needs additional information.

Important Elements

HTML Forms

An HTML form is used to collect information from users. Forms can contain input fields, labels, buttons, dropdowns and other controls.

Common Form Elements

  • <form> — Defines the form.
  • <label> — Defines a label.
  • <input> — Creates an input field.
  • <button> — Creates a button.

HTML Form Attributes

Form attributes provide additional information about how a form should behave when the user submits it.

Important Attributes

  • action — Specifies where form data is sent.
  • method — Specifies how data is submitted.
  • target — Specifies where the response opens.
  • autocomplete — Controls browser autocomplete.
