DAY 04 • EXCEL MASTERY

Formatting Cells

Learn how to make your Excel data clear, readable and visually organized using cell formatting and number formats.

🎯 Today's Goal

Learn the fundamentals of formatting cells so that your Excel worksheets become easier to read and understand.

📚 What You Will Learn

🎨 Cell Formatting

Understand how formatting can change the appearance and readability of data.

🔢 Number Formats

Learn how numbers can be displayed using appropriate number formats.

📅 Date Formats

Display dates in a clear and appropriate format.

🎯 Conditional Formatting

Use formatting rules to visually highlight important data.

💡 Why Formatting Matters

Good formatting makes a worksheet easier to understand. Different types of data can be displayed in a way that makes their meaning clear.

Example:

1500 → Number
₹1500 → Currency
25% → Percentage
24/08/2026 → Date

📝 Practice Task

Open Excel and create a small student marks table. Apply suitable formatting to the headings and values. Try different number formats and create a conditional formatting rule to highlight important values.
