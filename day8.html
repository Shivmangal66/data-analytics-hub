DAY 08 • EXCEL MASTERY

Sorting & Filtering Data

Learn how to reorder and narrow down datasets without deleting the underlying data.

🎯 Today's Goal

Learn to sort data using one or more columns and filter rows based on conditions.

📚 What You Will Learn

🔤 Sorting

Sort data A–Z or Z–A and organize rows based on values.

🔀 Multiple Columns

Sort by multiple columns using Sort → Add Level.

🔎 Filtering

Temporarily hide rows that do not match a condition.

🎨 Color Filtering

Sort or filter based on cell colors when appropriate.

📊 Worked Example

NameDepartmentSalary
RaviSales42000
AishaIT55000
MeeraSales48000
KaranIT51000
Sort by Department A–Z, then Salary High → Low.

Result: Aisha → Karan → Meera → Ravi

🔎 Filtering

Use Data → Filter or Ctrl + Shift + L to add filter arrows to the header row.

Text Filter → Department = "IT"
Number Filter → Salary > 50000
Date Filter → Last Month

📝 Practice Task

Enter a table of 10 employees with Name, Department and Salary. Sort it by Salary from highest to lowest. Then filter employees earning above 45,000.
