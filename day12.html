Data Validation & Dropdown Lists

Learn how to control what users can enter into Excel cells and create professional dropdown lists for clean and consistent data.

🎯 Today's Goal

Learn how Data Validation can restrict incorrect entries and how dropdown lists can make data entry faster, easier and more accurate.

📚 What You Will Learn

✅ Data Validation

Control the type of information that users can enter into a cell.

⬇️ Dropdown Lists

Create a list of predefined choices for users to select.

🔢 Number Restrictions

Allow only numbers within a specified range.

⚠️ Error Alerts

Display a warning when invalid data is entered.

💡 What is Data Validation?

Data Validation is an Excel feature used to control what kind of data can be entered into a cell.

Example:

Suppose a column contains employee departments.

Instead of allowing users to type anything, create a dropdown containing:

IT • HR • Sales • Finance

⬇️ Creating a Dropdown List

Follow these steps in Excel:

1. Select the cells
2. Go to Data
3. Select Data Validation
4. Choose List
5. Enter your allowed values
6. Click OK

📊 Example

Employee Department Status
Shiv IT Active
Rahul Sales Active
Aman HR Inactive
Department Dropdown:

IT | HR | Sales | Finance

Status Dropdown:

Active | Inactive

🔢 Number Validation

Data Validation can also restrict numerical values.

Example:

Allow only numbers between
0 and 100

This is useful for marks, percentages, ratings and scores.

⚠️ Error Alert

You can configure Excel to display an error message when someone enters invalid information.

Example Error:

"Please select a valid department from the dropdown."

📝 Practice Task

Create an employee table with the columns: Name, Department and Status.


Create a dropdown for Department containing: IT, HR, Sales and Finance.


Create another dropdown for Status containing: Active and Inactive.


Finally, create a marks column where only numbers from 0 to 100 are allowed.
