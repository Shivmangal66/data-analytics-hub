Power Query & Data Cleaning

Learn how to import, clean, transform and prepare messy data for professional analysis using Excel Power Query.

🎯 Today's Goal

Today you will learn how to turn messy raw data into clean and analysis-ready data using Power Query.

💡 Data Analysts often spend a large amount of time cleaning data before starting analysis.

📚 What You Will Learn

📥 Import Data

Import data from Excel files, CSV files and other supported sources.

🧹 Clean Data

Remove duplicates, errors and unwanted information.

🔄 Transform Data

Change columns, rows, data types and formats.

⚡ Refresh Data

Refresh queries when the source data changes.

💡 What is Power Query?

Power Query is an Excel feature used to import, connect, clean and transform data before using it for analysis.

Think of Power Query as a data preparation tool that lets you repeat the same cleaning process efficiently.

🧹 What is Data Cleaning?

Data Cleaning means finding and fixing problems in raw data so that the data becomes accurate, consistent and ready for analysis.

❌ Duplicates

Remove repeated records.

⚠️ Missing Values

Identify and handle blank values.

🔤 Text Problems

Fix extra spaces and inconsistent text.

🔢 Data Types

Make sure numbers, dates and text have the correct data type.

📋 Example of Messy Data

Name City Sales
Rahul Delhi 50000
Rahul Delhi 50000
PRIYA delhi 45000
Aman 35000
Neha Mumbai invalid
⚠️ Problems include duplicate records, extra spaces, inconsistent text and invalid values.

🛠️ Open Power Query

1

Open Excel.

2

Go to the Data tab.

3

Look for the Get & Transform Data section.

4

Choose a data source such as From Table/Range or From Text/CSV.

5

The Power Query Editor will open.

🧹 Remove Duplicates

Duplicate records can affect your analysis. Power Query allows you to remove duplicate rows.

1

Select the column or columns you want to check.

2

Go to Home → Remove Rows.

3

Select Remove Duplicates.

✂️ Remove Extra Spaces

Extra spaces can cause matching and analysis problems.

1

Select the required text column.

2

Go to Transform → Format.

3

Select Trim.

Trim removes unnecessary spaces from the beginning and end of text.

🔠 Change Text Case

Power Query can transform text into different formats.

UPPERCASE

Converts text to capital letters.

lowercase

Converts text to small letters.

Capitalize Each Word

Makes the first letter of each word uppercase.

Trim

Removes unnecessary spaces.

🔢 Change Data Type

Correct data types are important for accurate calculations and analysis.

Data Correct Type
50000 Whole Number / Decimal Number
25-08-2026 Date
Rahul Text
85.5 Decimal Number

❌ Handle Errors

Power Query can identify cells containing errors so that they can be replaced or removed.

1

Select the column containing errors.

2

Use the options under Remove Rows or Replace Values.

➕ Fill Missing Values

Missing values can sometimes be filled using a previous or next value, depending on the structure of your dataset.

💡 Always understand why a value is missing before replacing it. Do not blindly fill every blank cell.

🔀 Split Columns

A single column can sometimes contain multiple pieces of information.

Example:

Shiv Mishra

Can be split into:
First Name | Last Name
1

Select the column.

2

Select Split Column.

3

Choose a separator such as space, comma or another delimiter.

🔗 Merge Queries

Merge Queries allows you to combine information from two tables based on a common column.

Example: Combine an Employee table with a Department table using Employee ID.

📚 Append Queries

Append Queries is used to stack rows from multiple tables with similar columns.

Example: Combine January, February and March sales tables into one complete sales table.

🔄 Refresh Power Query

One of the biggest advantages of Power Query is that your transformation steps can be repeated when new source data arrives.

1

Update the source data.

2

Refresh the query.

3

Power Query applies the saved transformation steps to the refreshed data.

💼 Real-World Uses

📊 Sales Reports

Combine and clean monthly sales data.

👨‍💼 Employee Data

Clean employee records from multiple files.

📦 Inventory

Combine inventory files and standardize product information.

📈 Data Analytics

Prepare clean data before creating dashboards and reports.

⚠️ Common Mistakes

❌ Wrong Data Type

Numbers stored as text can cause calculation problems.

❌ Blindly Removing Data

Understand the data before deleting rows or columns.

❌ Ignoring Duplicates

Duplicate records can produce incorrect analysis.

❌ Not Refreshing

Refresh the query after source data changes.
