DAY 06 • EXCEL MASTERY

Basic Functions

Learn SUM, AVERAGE, MIN, MAX and COUNT to quickly summarize numerical data.

🎯 Today's Goal

Use Excel's basic functions to calculate totals, averages, minimum values, maximum values and counts.

📚 Functions You Will Learn

➕ SUM

Adds numbers in a selected range.

📊 AVERAGE

Calculates the average of numerical values.

⬇️ MIN

Returns the smallest value in a range.

⬆️ MAX

Returns the largest value in a range.

🔢 COUNT

Counts cells containing numbers.

💡 Formula Examples

SUM: =SUM(B2:B6)
AVERAGE: =AVERAGE(B2:B6)
MIN: =MIN(B2:B6)
MAX: =MAX(B2:B6)
COUNT: =COUNT(B2:B6)

📝 Practice Task

Create a table of 6 students' marks in 3 subjects. Use SUM to calculate each student's total, AVERAGE for the average, and MIN/MAX to find the lowest and highest score.
