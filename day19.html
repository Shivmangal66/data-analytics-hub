DAY 19 • EXCEL MASTERY

INDEX & MATCH

Learn how INDEX and MATCH work together to create flexible lookup solutions in Excel.

🎯 Today's Goal

Understand INDEX and MATCH separately and then combine them to look up information from a table.

📚 What You Will Learn

🔎 MATCH

Finds the position of a value inside a selected range.

📍 INDEX

Returns a value from a specified position in a range.

🔗 INDEX + MATCH

Combine both functions to create a flexible lookup formula.

💼 Practical Lookup

Use the combination to retrieve employee or sales information.

💡 What is MATCH?

MATCH searches for a value in a range and returns its position.

=MATCH(lookup_value, lookup_array, 0)
Example: If "Aman" is the third name in a list, MATCH can return 3.

📍 What is INDEX?

INDEX returns a value from a particular position in a range.

=INDEX(array, row_num)
Example: If the third cell in a salary range contains 50,000, INDEX can return 50,000.

📊 Sample Data

Employee ID Name Department Salary
101 Shiv IT 55000
102 Rahul Sales 45000
103 Aman HR 50000
104 Priya Finance 60000

🔗 INDEX + MATCH

INDEX and MATCH can be combined to find a value based on a lookup value.

=INDEX(D2:D5,MATCH(F2,A2:A5,0))

Here, Excel first uses MATCH to find the position of the Employee ID and then INDEX returns the corresponding Salary.

🛠️ How It Works

1

Enter an Employee ID in cell F2.

2

MATCH searches for that ID in A2:A5.

3

MATCH returns the position of the employee.

4

INDEX uses that position to return the corresponding salary.

💰 Example

If F2 contains Employee ID 103:

F2 = 103

=INDEX(D2:D5,MATCH(F2,A2:A5,0))

Result → 50000

⚖️ INDEX + MATCH vs VLOOKUP

Feature VLOOKUP INDEX + MATCH
Lookup Vertical Flexible
Formula Simple More advanced
Learning Beginner friendly Intermediate

⚠️ Common Mistakes

❌ Wrong Range

Make sure INDEX and MATCH ranges correspond correctly.

❌ Missing 0

Use 0 in MATCH when you need an exact match.

❌ Different Range Sizes

Keep the lookup and result ranges aligned.

❌ Wrong Lookup Value

Check that the lookup value actually exists in the source data.

📝 Practice Task

Create an employee table with Employee ID, Name, Department and Salary.


Enter an Employee ID into a separate cell.


Use INDEX + MATCH to return the employee's Name.


Create another INDEX + MATCH formula to return the employee's Salary.
