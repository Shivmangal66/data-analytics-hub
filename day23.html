Conditional Formatting

Learn how to automatically highlight important values, trends and patterns in Excel data.

🎯 Today's Goal

Learn how Conditional Formatting can automatically change the appearance of cells based on their values or conditions.

📚 What You Will Learn

🎨 Highlight Rules

Highlight cells based on numbers, text or dates.

📊 Data Bars

Display bars inside cells to compare numerical values visually.

🌈 Color Scales

Use different colors to identify low, medium and high values.

🔹 Icon Sets

Display icons to show performance, status or trends.

💡 What is Conditional Formatting?

Conditional Formatting is an Excel feature that automatically formats cells when they meet a specific condition.

💡 Example: In a marksheet, you can automatically highlight marks below 40 so that failed students are easy to identify.

🛠️ How to Apply Conditional Formatting

1

Select the cells you want to format.

2

Go to the Home tab.

3

Click Conditional Formatting.

4

Choose the rule you need.

5

Select the formatting style.

6

Click OK.

🔴 Highlight Cells Rules

Excel provides ready-made rules for highlighting cells based on their values.

Greater Than

Highlight values greater than a specified number.

Less Than

Highlight values below a specified number.

Equal To

Highlight cells containing a specific value.

Duplicate Values

Quickly identify duplicate records in a dataset.

📊 Data Bars

Data Bars display a horizontal bar inside each cell. Larger values receive longer bars.

Example: If sales values are 10,000, 30,000 and 50,000, the 50,000 value will have the longest data bar.

🌈 Color Scales

Color Scales use different colors to represent low, medium and high values.

Sales Interpretation
10,000 Low
35,000 Medium
80,000 High

🔹 Icon Sets

Icon Sets add symbols to cells based on their values or performance.

Example: Sales performance can be displayed using arrows such as ↑, → and ↓.

🧠 Formula-Based Formatting

You can also create your own Conditional Formatting rule using an Excel formula.

Example:

=B2<40

This condition can be used to identify students whose marks are below 40.

💼 Real-World Uses

📈 Sales Analysis

Highlight high and low performing sales values.

🎓 Student Results

Highlight failed or high-scoring students.

📦 Inventory

Identify products with low stock.

👨‍💼 Employee Data

Highlight attendance or performance issues.

⚠️ Common Mistakes

❌ Wrong Range

Always select the correct range before applying a formatting rule.

❌ Too Many Rules

Too many overlapping rules can make your report confusing.

❌ Wrong Condition

Check your condition carefully before applying the rule.

❌ Ignoring Duplicates

Duplicate highlighting is useful when cleaning datasets.
