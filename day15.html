DAY 15 • EXCEL MASTERY

Introduction to Charts

Learn how to turn Excel data into visual charts that make comparisons, trends and patterns easier to understand.

🎯 Today's Goal

Understand the basics of Excel charts and learn how to select data and create a suitable chart for presenting information visually.

📚 What You Will Learn

📊 Column Chart

Useful for comparing values between different categories.

📈 Line Chart

Useful for showing changes and trends over time.

🥧 Pie Chart

Useful for showing how categories contribute to a total.

📉 Bar Chart

Useful for comparing categories horizontally.

💡 What is a Chart?

A chart is a visual representation of data. Instead of looking only at numbers in rows and columns, charts help us understand information quickly.

🛠️ How to Create a Chart in Excel

1

Enter your data into rows and columns.

2

Select the complete data range.

3

Go to the Insert tab.

4

Choose a suitable chart type.

5

Add a chart title and format the chart as required.

🎯 Choosing the Right Chart

Column

Best for comparing categories.

Line

Best for trends over time.

Pie

Best for parts of a whole.

Bar

Best for horizontal comparisons.

📝 Practice Task

Create a table containing monthly sales for six months.


Select the data and create a Column Chart.


Give your chart a meaningful title such as "Monthly Sales Report".


Now create a Line Chart using the same data and compare which chart makes the trend easier to understand.
