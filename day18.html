🎛️ What is a Slicer?

A Slicer is a visual filtering control used with PivotTables. Instead of opening a normal filter menu, users can click buttons to filter the report.

💡 Example: If your PivotTable contains Department data, a Slicer can provide buttons such as IT, HR, Sales and Finance.

🛠️ Create a Slicer

1

Select your PivotTable.

2

Go to the PivotTable options.

3

Select Insert Slicer.

4

Choose the field you want to filter.

5

Use the Slicer buttons to filter your report.

📅 Grouping Data

Grouping allows you to combine related values into larger categories.

📆 Dates

Group dates by Years, Quarters or Months.

🔢 Numbers

Group numerical values into ranges.

Example: Instead of showing every individual transaction date, group the dates by Month to create a monthly sales report.

🧮 Calculated Fields

A Calculated Field allows you to create a new calculation using fields already present in your PivotTable source data.

Example:

Profit = Sales - Cost

If Sales = 50,000 and Cost = 30,000

Profit = 20,000
