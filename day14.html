🚀 Mini Project

Create a simple Employee Management Sheet using the Excel concepts you have learned.

📋 Project Structure

Employee ID Name Department Salary Status
101 Shiv IT 55000 Active
102 Rahul Sales 45000 Active
103 Aman HR 50000 Inactive
104 Priya Finance 60000 Active

🛠️ Build the Project

1

Create the employee table with ID, Name, Department, Salary and Status.

2

Create a dropdown list for Department: IT, HR, Sales and Finance.

3

Create a dropdown list for Status: Active and Inactive.

4

Use conditional formatting to highlight inactive employees.

5

Create a separate Employee ID input cell and use VLOOKUP to return employee details.

🔎 VLOOKUP Challenge

Suppose cell G2 contains the Employee ID. Use VLOOKUP to return the employee's Name.

=VLOOKUP(G2,A2:E5,2,FALSE)

Now change the column number to return the employee's Department or Salary.

🎨 Conditional Formatting Challenge

Highlight employees whose Status is Inactive.

=$E2="Inactive"
