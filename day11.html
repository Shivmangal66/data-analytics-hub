Advanced Conditional Formatting

Learn how to use formula-based conditional formatting to automatically highlight important information in your Excel datasets.

🎯 Today's Goal

Learn how to create advanced conditional formatting rules using formulas so Excel can automatically highlight cells or complete rows based on conditions.

📚 What You Will Learn

🎨 Formula-Based Formatting

Create your own formula to decide when formatting should be applied.

🔴 Highlight Rows

Automatically highlight an entire row when a condition is satisfied.

📊 Multiple Conditions

Combine logical conditions with AND and OR.

⚡ Dynamic Formatting

Formatting changes automatically when the underlying data changes.

💡 Formula-Based Conditional Formatting

Suppose you have a student table and want to highlight students who failed.

Formula:

=$D2="Fail"

This rule can be applied to the complete data range to highlight rows where the Status column contains "Fail".

📊 Worked Example

Name Math Science Status
Aisha 88 92 Pass
Ravi 35 45 Fail
Meera 78 81 Pass
Example rule:
=$D2="Fail"

Result → Ravi's complete row can be highlighted.

🔗 Using AND

You can use AND when multiple conditions must be true at the same time.

=AND($B2<40,$C2<40)

This can identify students who scored below 40 in both subjects.

📝 Practice Task

Create a student marks table with Name, Math, Science and Status columns.


Create a formula-based conditional formatting rule that highlights the complete row whenever Status equals "Fail".


Then create another rule to identify students who scored below 40 in both subjects.
