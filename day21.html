DAY 21 • EXCEL MASTERY

IF, AND & OR Functions

Learn how to make logical decisions in Excel using IF, AND and OR functions.

🎯 Today's Goal

Learn how Excel can automatically evaluate conditions and return different results based on whether those conditions are TRUE or FALSE.

📚 What You Will Learn

🧠 IF

Returns one result when a condition is TRUE and another when it is FALSE.

🔗 AND

Checks whether all specified conditions are TRUE.

🔀 OR

Checks whether at least one of the specified conditions is TRUE.

🚀 Combined Logic

Combine IF with AND or OR to create advanced decision-making formulas.

🧠 IF Function

The IF function checks a condition and returns one value if the condition is TRUE and another value if the condition is FALSE.

=IF(logical_test,value_if_true,value_if_false)

Example:
=IF(A2>=40,"Pass","Fail")
If the value in A2 is 40 or more, the result will be Pass. Otherwise, it will be Fail.

🔗 AND Function

AND returns TRUE only when all the specified conditions are TRUE.

=AND(A2>=40,B2>=40)

Both conditions must be TRUE.
Example: A student must score at least 40 in both subjects to satisfy the condition.

🔀 OR Function

OR returns TRUE when at least one of the specified conditions is TRUE.

=OR(A2>=40,B2>=40)

At least one condition must be TRUE.

🚀 IF + AND

IF and AND can be combined when multiple conditions must be satisfied.

=IF(AND(B2>=40,C2>=40),"Pass","Fail")

In this example, the student must score at least 40 in both Maths and English.

🚀 IF + OR

IF and OR can be combined when at least one condition should be satisfied.

=IF(OR(B2>=80,C2>=80),"Excellent","Normal")

If the student scores 80 or more in either subject, the result becomes Excellent.

📋 Quick Comparison

Function Purpose Example
IF Make a decision =IF(A2>=40,"Pass","Fail")
AND All conditions must be TRUE =AND(A2>40,B2>40)
OR At least one condition TRUE =OR(A2>40,B2>40)

⚠️ Common Mistakes

❌ Missing Quotes

Text results such as "Pass" and "Fail" should be written inside quotation marks.

❌ Wrong Comparison

Check whether you need >, <, >=, <= or =.

❌ Confusing AND & OR

AND requires all conditions while OR requires only one condition.

❌ Missing Brackets

Always check the parentheses in nested formulas.
