DAY 16 • EXCEL MASTERY

Advanced Charts & Formatting

Take your Excel charts to the next level by improving titles, labels, legends, axes and overall presentation.

🎯 Today's Goal

Learn how to format and customize Excel charts so that your reports and dashboards look clean, professional and easy to understand.

📚 What You Will Learn

🏷️ Chart Titles

Add clear and meaningful titles to your charts.

🔢 Data Labels

Display actual values directly on the chart.

📌 Legends

Use legends to explain different data series.

📐 Axis Formatting

Improve chart axes, scales and number formats.

💡 Why Chart Formatting Matters

A chart should not only display data. It should also communicate information clearly. Proper formatting makes a chart easier to read and more professional.

💡 Tip: Avoid unnecessary formatting. Keep your chart simple and focus on the information that matters.

📊 Example Data

Month Sales Expenses
January 50000 30000
February 65000 35000
March 80000 42000
April 72000 39000

🛠️ Format Your Chart

1

Select your chart and add a meaningful chart title.

2

Turn on data labels when the exact values are important.

3

Position the legend where it does not hide important information.

4

Format the horizontal and vertical axes so that numbers are easy to understand.

5

Remove unnecessary chart elements that make the chart difficult to read.

📈 Professional Chart Checklist

✓ Clear Title

The viewer should immediately understand what the chart represents.

✓ Correct Labels

Important values should be easy to identify.

✓ Useful Legend

Multiple data series should be clearly identified.

✓ Clean Design

Avoid unnecessary elements and clutter.

🎯 When to Use Data Labels?

Data labels are useful when the exact value of each data point is important to the viewer.


For example, in a monthly sales report, displaying the exact sales amount can make the chart easier to understand.

📝 Practice Task

Create a table containing Month, Sales and Expenses for at least six months.


Create a chart comparing Sales and Expenses.


Add a meaningful chart title, data labels and a suitable legend.


Finally, format the axes and remove any unnecessary chart elements.
