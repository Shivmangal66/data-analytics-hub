DAY 20 • EXCEL MASTERY

Text Functions

Learn how to clean, extract, combine and manipulate text data using powerful Excel text functions.

🎯 Today's Goal

Learn the most useful Excel Text Functions for data cleaning, formatting and preparing real-world datasets for analysis.

📚 What You Will Learn

🔤 LEFT

Extract characters from the beginning of a text string.

🔤 RIGHT

Extract characters from the end of a text string.

🔤 MID

Extract characters from a specific position in a text string.

📏 LEN

Count the number of characters in a text string.

🔗 CONCAT

Combine text from multiple cells.

🧹 TRIM

Remove unnecessary spaces from text.

🔤 LEFT Function

LEFT returns a specified number of characters from the beginning of a text string.

=LEFT(text, num_chars)

Example:
=LEFT("SHIVMISHRA",4)

Result → SHIV

🔤 RIGHT Function

RIGHT returns characters from the end of a text string.

=RIGHT("SHIVMISHRA",5)

Result → ISHRA

🔤 MID Function

MID extracts characters starting from a specific position.

=MID("SHIVMISHRA",5,5)

Result → MISHR
💡 MID syntax: MID(text, start_num, num_chars)

📏 LEN Function

LEN counts the total number of characters in a text string, including spaces.

=LEN("SHIV MISHRA")

Result → 11

🔗 CONCAT Function

CONCAT combines text from different cells into a single text value.

=CONCAT(A2," ",B2)

If A2 = Shiv
If B2 = Mishra

Result → Shiv Mishra

🧹 TRIM Function

TRIM removes extra spaces from text while keeping single spaces between words.

=TRIM(A2)
💡 TRIM is extremely useful when cleaning imported or copied datasets.

📊 Practical Example

Full Name First Name Last Name
Shiv Mishra Shiv Mishra
Rahul Kumar Rahul Kumar
Priya Sharma Priya Sharma
Data analysts frequently need to split and clean names, emails, IDs and other text fields.

🛠️ Common Text Functions

Function Purpose Example
LEFT Extract from beginning =LEFT(A2,5)
RIGHT Extract from end =RIGHT(A2,4)
MID Extract from middle =MID(A2,3,5)
LEN Count characters =LEN(A2)
CONCAT Combine text =CONCAT(A2,B2)
TRIM Remove extra spaces =TRIM(A2)

⚠️ Common Mistakes

❌ Wrong Character Count

Check the number of characters you actually want to extract.

❌ Ignoring Spaces

Spaces are also characters and can affect your results.

❌ Wrong Starting Position

MID requires the correct starting position.

❌ Dirty Data

Use TRIM when imported data contains unnecessary spaces.

📝 Practice Task

Create a list containing at least 10 full names.


Use text functions to extract the first characters and last characters.


Use LEN to calculate the length of each name.


Create separate First Name and Last Name columns.


Use CONCAT to combine the names again.


Finally, use TRIM to clean extra spaces.
