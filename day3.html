DAY 03 • EXCEL MASTERY

Basic Formulas & Cell References

Learn how Excel formulas work and understand how cell references are used to perform calculations automatically.

🎯 Today's Goal

Understand basic Excel formulas, mathematical operators and the difference between relative and absolute cell references.

📚 What You Will Learn

🧮 Basic Formulas

Learn how to create calculations in Excel using formulas that start with an equals sign.

➕ Mathematical Operators

Use operators such as +, -, *, and / to perform basic calculations.

🔗 Cell References

Use cell addresses such as A1 and B1 inside formulas instead of typing values again.

📌 Relative & Absolute References

Understand how relative references change and how absolute references stay fixed.

💡 Formula Examples

In Excel, a formula normally starts with the = symbol.

=A1+B1
=A1-B1
=A1*B1
=A1/B1

📌 Understanding Cell References

Relative Reference: A1

When copied to another cell, the reference can change.

Absolute Reference: $A$1

When copied, the reference remains fixed.

📝 Practice Task

Create two columns with numbers in Excel. Use formulas to add, subtract, multiply and divide the values. Then try copying the formula to another row and observe how cell references change.
