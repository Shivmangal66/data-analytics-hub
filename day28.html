Advanced Formulas & Conditional Logic

Learn how to use logical formulas to make decisions, classify data and build smarter Excel reports.

🎯 Today's Goal

Today you will learn how Excel can automatically make decisions based on conditions.

💡 Conditional formulas are extremely useful for Data Analysis, reporting and automation.

📚 What You Will Learn

🧠 IF

Return one result when a condition is TRUE and another when it is FALSE.

🔗 AND

Check whether multiple conditions are all TRUE.

🔀 OR

Check whether at least one condition is TRUE.

🪜 IFS

Evaluate multiple conditions in a structured way.

💡 What is Conditional Logic?

Conditional Logic means checking whether a condition is true or false and then performing an action based on the result.

Example: If marks are 40 or above, display "Pass"; otherwise display "Fail".

1️⃣ IF Function

The IF function checks a condition and returns one value if the condition is TRUE and another value if it is FALSE.

=IF(condition, value_if_true, value_if_false)

🧮 IF Example

Suppose marks are stored in cell B2.

=IF(B2>=40,"Pass","Fail")
Marks ≥ 40 → Pass
Marks < 40 → Fail

2️⃣ AND Function

AND returns TRUE only when all specified conditions are TRUE.

=AND(condition1, condition2)

🧮 AND + IF Example

A student passes only when marks are at least 40 and attendance is at least 75%.

=IF(AND(B2>=40,C2>=75%),"Pass","Fail")
Both conditions must be TRUE.

3️⃣ OR Function

OR returns TRUE when at least one of the specified conditions is TRUE.

=OR(condition1, condition2)

🧮 OR + IF Example

Suppose a customer receives a discount if their sales are above ₹50,000 OR they are a premium customer.

=IF(OR(B2>50000,C2="Premium"),"Discount","No Discount")

4️⃣ IFS Function

IFS is useful when you need to check multiple conditions without creating many nested IF statements.

=IFS(B2>=90,"A+",B2>=80,"A",B2>=70,"B",B2>=60,"C",TRUE,"Fail")

🔢 COUNTIF

COUNTIF counts cells that meet a specific condition.

=COUNTIF(range, criteria)

Example:

=COUNTIF(B2:B20,">=40")

➕ SUMIF

SUMIF adds values that meet a specified condition.

=SUMIF(range, criteria, sum_range)

Example:

=SUMIF(A2:A20,"North",B2:B20)

📊 AVERAGEIF

AVERAGEIF calculates the average of values that meet a specific condition.

=AVERAGEIF(range, criteria, average_range)

🧩 Useful Conditional Functions

IF

Make a decision based on a condition.

AND

All conditions must be TRUE.

OR

At least one condition must be TRUE.

COUNTIF

Count values matching a condition.

SUMIF

Sum values matching a condition.

AVERAGEIF

Calculate average based on a condition.

💼 Real-World Uses

🎓 Student Analysis

Automatically classify students as Pass, Fail or different grades.

💰 Sales Analysis

Identify high-performing salespeople and regions.

👨‍💼 Employee Analysis

Identify employees meeting performance conditions.

📦 Inventory

Identify products that need restocking.

⚠️ Common Mistakes

❌ Missing Quotes

Text results such as "Pass" should be written inside quotation marks.

❌ Wrong Cell Reference

Check that your formula points to the correct cells.

❌ Incorrect Condition

Carefully check operators such as >, <, >= and <=.

❌ Complex Formula

Break complicated logic into smaller steps when necessary.
