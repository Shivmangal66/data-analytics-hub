Data Validation

Learn how to control data entry, create drop-down lists and reduce mistakes in Excel worksheets.

🎯 Today's Goal

Learn how Data Validation helps you control what users can enter into an Excel cell and how to create professional drop-down lists.

📚 What You Will Learn

✅ Data Validation

Control the type of information that can be entered into a cell.

🔽 Drop-down List

Create selectable options inside an Excel cell.

🔢 Number Rules

Restrict cells to specific numbers or ranges.

📅 Date Rules

Allow users to enter only valid dates within a selected range.

💡 What is Data Validation?

Data Validation is an Excel feature used to control the type of data that users can enter into a cell.

💡 Example: If a Department column should contain only IT, HR, Sales or Finance, you can create a drop-down list instead of allowing users to type anything.

🔽 Create a Drop-down List

1

Select the cell or cells where you want the drop-down list.

2

Go to the Data tab.

3

Select Data Validation.

4

Choose List as the validation criteria.

5

Enter your options, for example: IT, HR, Sales, Finance.

6

Click OK.

🔢 Number Validation

Data Validation can also restrict numbers. For example, you may want Experience to be between 0 and 40 years.

Validation Rule:

Whole Number → between → 0 and 40
This prevents users from accidentally entering values such as -5 or 100.

📅 Date Validation

You can restrict a cell to accept dates only within a specific period.

Date → between → Start Date → End Date

This is useful for attendance sheets, employee records, sales reports and project tracking.

⚠️ Input Message

Data Validation can display a message when a user selects the cell.

Example:

Title: Department
Message: Please select a department from the drop-down list.

🚫 Error Alert

Error Alerts can warn users when they enter invalid data.

🛑 Stop

Prevents invalid data from being entered.

⚠️ Warning

Warns the user but can allow the entry.

ℹ️ Information

Shows an information message about the validation rule.

💼 Real-World Uses

👨‍💼 Employee Data

Department and employee status drop-downs.

🎓 Student Data

Course, semester and result selection.

💰 Sales Data

Product category and sales status selection.

📦 Inventory

Product type and stock status selection.

⚠️ Common Mistakes

❌ Wrong Range

Make sure the correct cells are selected before applying validation.

❌ Wrong List Items

Check that all required options are included in the list.

❌ No Error Alert

Configure an appropriate error alert for invalid entries.

❌ Manual Typing

Use drop-down lists when users should choose from fixed options.
