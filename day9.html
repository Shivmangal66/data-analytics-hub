DAY 09 • EXCEL MASTERY

The IF Function & Logical Tests

Teach Excel to make decisions by testing conditions and returning different results.

🎯 Today's Goal

Understand how IF evaluates a condition and returns one result when TRUE and another when FALSE.

📚 Logical Operators

=

Equal to

>

Greater than

<

Less than

>=

Greater than or equal to

<=

Less than or equal to

<>

Not equal to

💡 IF Syntax

=IF(logical_test, value_if_true, value_if_false)

📊 Worked Example

StudentScoreResult
Aisha82=IF(B2>=40,"Pass","Fail") → Pass
Ravi35=IF(B3>=40,"Pass","Fail") → Fail
Meera40=IF(B4>=40,"Pass","Fail") → Pass

🏆 Nested IF

Use one IF inside another when you need more than two outcomes.

=IF(B2>=90,"A",IF(B2>=75,"B",IF(B2>=50,"C","F")))

95 → A
80 → B
60 → C
30 → F

🔗 AND / OR with IF

=IF(AND(B2>=40,C2>=40),"Pass","Fail")

=IF(OR(B2="VIP",C2>10000),"Priority","Standard")
