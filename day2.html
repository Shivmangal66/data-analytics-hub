Entering & Editing Data

Learn how to enter and edit information in Excel and become comfortable working with data inside cells.

🎯 Today's Goal

Practice entering and editing data in Excel and understand how Excel handles information entered into cells.

📚 Day 2 Topics

⌨️ Entering Data

Practice entering information into Excel cells.

✏️ Editing Data

Learn how to modify information already entered in a cell.

🔢 Data Types

Understand the different kinds of information you can work with.

⚡ AutoFill & Flash Fill

Explore Excel features that help speed up repetitive data entry.

💡 Practice

Open Excel and create a small table with names, numbers and other information. Practice entering, changing and filling data in different cells.

Example:

Name → Shiv
Age → 18
Course → Data Analytics
Score → 85

📝 Practice Task

Create a small student data table in Excel. Enter at least 5 records and practice editing the values. Then try Excel's AutoFill and Flash Fill features.
