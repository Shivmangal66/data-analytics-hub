Pivot Tables & Pivot Charts

Learn how to summarize large datasets, analyze business information and create interactive reports using Pivot Tables.

🎯 Today's Goal

Learn how to quickly summarize hundreds or thousands of rows of data without writing complicated formulas.

💡 Pivot Tables are one of the most important Excel tools for Data Analysts.

📚 What You Will Learn

📊 Pivot Table

Summarize and analyze large datasets quickly.

🔄 Rows & Columns

Organize your data into meaningful categories.

🧮 Values

Calculate Sum, Count, Average and other summaries.

📈 Pivot Chart

Turn Pivot Table results into interactive charts.

💡 What is a Pivot Table?

A Pivot Table is an Excel tool used to summarize, analyze and present large amounts of data in a simple report.

Example: If you have 1,000 sales records, a Pivot Table can quickly show total sales by region, product or month.

📋 Sample Dataset

Order ID Product Region Category Sales
1001 Laptop North Electronics 55000
1002 Mouse West Accessories 2500
1003 Monitor South Electronics 18000
1004 Keyboard East Accessories 4500
1005 Laptop West Electronics 62000

🛠️ How to Create a Pivot Table

1

Select your complete dataset including the column headings.

2

Go to the Insert tab.

3

Click PivotTable.

4

Select where you want to place the Pivot Table.

5

Drag fields into Rows, Columns, Values or Filters.

🧩 Pivot Table Fields

📌 Rows

Used to display categories vertically. Example: Region.

📌 Columns

Used to compare categories horizontally.

📌 Values

Used for calculations such as Sum, Count and Average.

📌 Filters

Used to filter the entire Pivot Table based on selected criteria.

🧮 Common Pivot Table Calculations

SUM

Calculates total values.

COUNT

Counts the number of records.

AVERAGE

Calculates the average value.

MAX / MIN

Finds the highest or lowest value.

📈 Pivot Chart

A Pivot Chart is a visual representation of Pivot Table data.

💡 When you change or filter the Pivot Table, the Pivot Chart can update accordingly.

🛠️ How to Create a Pivot Chart

1

Click anywhere inside your Pivot Table.

2

Go to PivotTable Analyze or Insert.

3

Select PivotChart.

4

Select a suitable chart type.

5

Format the chart and add a meaningful title.

🎯 Real-World Questions You Can Answer

⚠️ Common Mistakes

❌ Blank Headers

Make sure every column has a proper heading.

❌ Empty Rows

Avoid unnecessary blank rows inside your dataset.

❌ Wrong Field

Put categories in Rows and numerical data in Values where appropriate.

❌ Forgetting Refresh

Refresh the Pivot Table when the source data changes.
