Excel Data Analytics Final Project

Put everything you learned during the 30-Day Excel journey together and build a professional Sales Analytics Dashboard.

🎯 Final Project Objective

Build a Sales Analytics Dashboard that helps a business understand its sales performance.

💰 Sales

Analyze total revenue and sales trends.

📦 Products

Identify the best and worst performing products.

🌍 Regions

Compare performance across regions.

👨‍💼 Customers

Analyze customer and order information.

📋 Step 1 — Create the Dataset

Create an Excel table containing at least 100–500 sales records.

Column Example
Order ID ORD1001
Order Date 25-08-2026
Customer Rahul
Product Laptop
Category Electronics
Region North
Quantity 3
Unit Price 55000
Sales 165000

🧹 Step 2 — Clean the Data

1

Remove duplicate records.

2

Remove unnecessary spaces.

3

Standardize names and categories.

4

Check missing values.

5

Correct dates and numerical data types.

💡 You can use the Power Query techniques learned on Day 29 for this step.

🧮 Step 3 — Calculate Sales

If Quantity is in column G and Unit Price is in column H, calculate Sales:

=G2*H2

Copy the formula down for all records.

🔎 Step 4 — Use Lookup Functions

Use the lookup functions from Day 27 to retrieve information from supporting tables.

=XLOOKUP(A2,ProductID,ProductName)

=VLOOKUP(A2,ProductTable,2,FALSE)

🧠 Step 5 — Add Conditional Logic

Create a Performance column using IF or IFS.

=IFS(I2>=100000,"Excellent", I2>=50000,"Good", I2>=20000,"Average", TRUE,"Low")
