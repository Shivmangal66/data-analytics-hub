COUNTIF, COUNTIFS, SUMIF & SUMIFS

Learn how to count and total data based on one or more conditions.

🎯 Today's Goal

Use conditional counting and summing to analyze only the rows that meet your conditions.

📚 Functions

🔢 COUNTIF

Counts cells matching one condition.

🔢 COUNTIFS

Counts rows matching several conditions.

➕ SUMIF

Adds numbers matching one condition.

➕ SUMIFS

Adds numbers matching several conditions.

📊 Sales Example

RegionSales
North4500
South3200
North5100
East2900
North3900

💡 Formulas

COUNTIF
=COUNTIF(A2:A6,"North")
Result → 3

COUNTIFS
=COUNTIFS(A2:A6,"North",B2:B6,">4000")
Result → 2

SUMIF
=SUMIF(A2:A6,"North",B2:B6)
Result → 13500

SUMIFS
=SUMIFS(B2:B6,A2:A6,"North",B2:B6,">4000")
Result → 9600

📌 Quick Comparison

Function Question
COUNTIF How many rows match ONE condition?
COUNTIFS How many rows match SEVERAL conditions?
SUMIF What's the total for ONE condition?
SUMIFS What's the total for SEVERAL conditions?

📝 Practice Task

Create a 12-row sales table with Region, Product and Amount columns. Write a COUNTIF for one region and a SUMIFS for one region AND one product.

⚠️ Remember: text criteria should be written inside quotes, such as "North" or ">4000".
