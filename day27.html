DAY 27 • EXCEL MASTERY

VLOOKUP, HLOOKUP & XLOOKUP

Learn how to search for information in Excel and automatically return the related value from another table.

🎯 Today's Goal

Today you will learn Excel Lookup Functions. These functions are extremely useful when working with multiple datasets.

💡 Lookup functions help you find a value from one table and bring the related information from another table.

📚 What You Will Learn

🔎 VLOOKUP

Search vertically through the first column of a table.

↔️ HLOOKUP

Search horizontally through the first row of a table.

🚀 XLOOKUP

A modern and flexible lookup function for Excel.

⚠️ IFERROR

Handle lookup errors and display meaningful messages.

💡 What is a Lookup Function?

A Lookup Function searches for a specific value in a range and returns related information from another column or row.

Example: Enter an Employee ID and automatically find the employee's Name, Department and Salary.

📋 Sample Employee Data

Employee ID Name Department Salary
E101 Rahul Sales 35000
E102 Aman IT 45000
E103 Priya HR 40000
E104 Neha Finance 48000
E105 Ravi Marketing 42000

🔎 VLOOKUP

VLOOKUP means Vertical Lookup. It searches for a value in the first column of a table and returns a value from another column.

=VLOOKUP(lookup_value, table_array, col_index_num, FALSE)

🧮 VLOOKUP Example

Suppose cell A2 contains:

A2 = "E103"

To find the employee's name:

=VLOOKUP(A2,A2:D6,2,FALSE)
Result: Priya

🧩 VLOOKUP Arguments

Argument Meaning
lookup_value Value you want to search.
table_array Range containing your data.
col_index_num Column number to return.
FALSE Exact match.

↔️ HLOOKUP

HLOOKUP means Horizontal Lookup. It searches for a value across the first row of a table.

=HLOOKUP(lookup_value, table_array, row_index_num, FALSE)
💡 VLOOKUP searches vertically. HLOOKUP searches horizontally.

🚀 XLOOKUP

XLOOKUP is a modern lookup function that is more flexible than traditional VLOOKUP and HLOOKUP.

=XLOOKUP(lookup_value, lookup_array, return_array)

🧮 XLOOKUP Example

Find the employee name using Employee ID.

=XLOOKUP(A2,A2:A6,B2:B6)
If A2 contains E103, the result will be Priya.

⭐ VLOOKUP vs XLOOKUP

Feature VLOOKUP XLOOKUP
Search Direction Mostly vertical Flexible
Return Left Value Limited Yes
Exact Match Possible Default behavior
Flexible Return Limited Yes
Modern Excel Older function Recommended

🛡️ IFERROR with Lookup

Sometimes a lookup value does not exist. Excel may show an error such as #N/A.

=IFERROR(XLOOKUP(A2,A2:A6,B2:B6),"Not Found")
Instead of displaying an error, Excel will display Not Found.

💼 Real-World Uses

👨‍💼 Employee Data

Find employee name, department and salary using Employee ID.

📦 Product Data

Find product price using Product ID.

🎓 Student Records

Find student marks and course using Roll Number.

💰 Sales Data

Match customer IDs with sales information.

⚠️ Common VLOOKUP Mistakes

❌ Wrong Column Number

Check the column index carefully.

❌ Missing FALSE

Use FALSE when you need an exact match.

❌ Lookup Column

VLOOKUP searches in the first column of the selected table.

❌ Spelling Differences

Make sure lookup values match correctly.
